## 1. 实机边界与恢复

| 编号 | 场景 | 核对内容 |
| --- | --- | --- |
| H01 | 三种分发刷新、重新绑定与旧格式升级 | 状态哈希、单一控制器、标准变量、原生保存后短指针 |
| H02 | 停止生成、重复结束、重新生成 | 半成品不提交，结束不重复执行，新结果以正确父状态计算 |
| H03 | 编辑前楼与重放后续 | 显式阻止错误接续，重放生成新修订，旧修订可检查 |
| H04 | 删除末楼、中间楼、当前/非当前 Swipe | 恢复剩余链，保留必要祖先，回复下标与变量槽一致 |
| H05 | 复制/分支、切聊天、清缓存后恢复 | 文件独立恢复，迟到结果不能进入其他会话 |
| H06 | 保存前失败、已保存但响应丢失 | 保留原候选，重试不重跑，正式快照不混入候选 |
| H07 | 两个独立客户端/标签页交替与同时写 | 过期基线拒绝覆盖，刷新后可继续，区别接口并发与真实标签页 |
| H08 | 独立操作模型成功、超时、取消、迟到响应 | 释放忙碌、不错误落盘、保留有效恢复路径；控制响应和真实模型分别标注 |
| H09 | PNG 导出再导入、助手脚本/定义保留 | 使用酒馆实际导入导出接口，比对定义、脚本、变量，导入后可初始化 |
| H10 | 测试环境收尾 | 记录测试角色/聊天/扩展，恢复此前使用的预设与页面；只清理本轮自建数据 |

每项产出可重现步骤、预期值、实际值、证据路径和剩余限制。发现缺陷由主代理修复，并增加与触发条件对应的回归。

## 2. 自动检查与发布物

1. 同步开发计划、实现状态、验证记录、兼容范围和当前正式变量语义，移除过期的“未启用缓存”等判断。
2. 建立跨平台自动检查：依赖安装、类型检查、全部测试、三载体构建、构建包检查；真实酒馆和模型请求不在公共 CI 自动运行。
3. 提供可重复运行的发布打包命令，生成原生扩展包、动态分发包、内嵌脚本包、完整对应源码与校验清单。
4. 发布包排除本机验收 HUD、个人配置、密钥、日志、node_modules 和临时测试聊天；包含协议、第三方声明、安装说明和对应源码。
5. 验证干净源码安装/构建和解包后的安装布局；校验 manifest、版本、脚本入口及源码引用。
6. 整理当前改动与变更说明，核对 GitHub 写入能力，具备权限后同步仓库与预览发布。权限不足时仍完成本地交付并明确远程待办。
