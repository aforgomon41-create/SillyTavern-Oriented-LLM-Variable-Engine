# 后端首版验证记录

日期：2026-10-26（Asia/Shanghai）。项目版本：0.5.0。此记录描述实际验证，企划中的其余目标不据此视为已完成。

## 自动验证

`npm run check`：类型检查、**71 项自动测试**、浏览器构建，以及构建包在独立 JavaScript 上下文中的运行检查，全部通过。

自动测试覆盖核心算子/group、事务回退、异步和跨字段校验、实体/引用/模块、默认值/变换、投影/宏、历史分支、动作去重、保存失败草稿、控制器并发和迟到请求。准确数量以最新测试输出为准。

测试文件：`tests/core.test.ts`、`tests/history.test.ts`、`tests/host.test.ts`、`tests/controller.test.ts`、`tests/regression.test.ts`。

## 真实宿主

`npm run test:host` 连接用户提供的 `http://localhost:11451`，由 `/version` 确认 **SillyTavern 1.19.0**。通过真实 API 创建独立临时角色、聊天与分支，验证：

1. Genesis 保存及回读。
2. 从正文提取操作并扣血。
3. group 中扣钱/物品搬移一起成功。
4. 失败 group 完整回退。
5. 相同 actionId 重试不重复扣钱。
6. 仅从回读的聊天归档恢复相同状态哈希。
7. 旧提交修订仍可恢复。
8. TOON 与紧凑 JSON 使用同一投影。
9. 独立分支文件恢复结果一致。

最新结构化结果在 `test-results/host-1.19.json`。脚本只删除自己创建的 UUID 临时角色及其聊天；清理结果为 cleanup=true。没有调用付费模型。

## 验证边界

真实宿主验证覆盖服务端保存/回读；生成生命周期、宏注册、独立操作模型、超时及原生准入以源码核对和模拟宿主自动测试验证。尚未在真实浏览器中完整跑完所有生成入口；IndexedDB 使用 fake-indexeddb 验证。没有把助手/第三方自行联网的入口标为可拦截。性能与大卡规模尚未验收。

核心和历史审查中由主代理核实并修复的问题包括：整对象输入绕过休眠/数值规则、动态默认函数在指纹阶段被意外调用、实体交换改变 ID 身份、容器删除绕过引用清理、缓存掩盖损坏归档、旧动作重试返回过期修订，以及部分异步选择覆盖风险。审查与修改由不同职责执行，所有代码均由主代理修改。
