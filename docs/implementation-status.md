## 性能样例

环境：Windows x64，Node v22.19.0；人工构造数据。以下为中位耗时，不是所有角色卡的保证。

| 场景 | 约 9 KB / 50 实体 | 约 94 KB / 500 实体 |
|---|---:|---:|
| 一条增加操作 | 1.08 ms | 7.21 ms |
| 10 条操作组成 group | 5.48 ms | 49.12 ms |
| 单实体 JSON 投影 | 0.07 ms | 0.54 ms |
| 100 楼冷恢复 | 45.66 ms | 314.92 ms |

同一基准把实体索引替换为基线版本单独运行时，500 实体的一条操作约 34.42 ms、10 条 group 约 303.29 ms。优化结果保留原状态语义和所有校验。冷恢复的成本仍随历史长度增长，后续需要真实浏览器、长历史及 L/XL 验收。

运行 `npm run benchmark`，结果写入 `test-results/performance.json`；对照记录为 `test-results/performance-before-index.json`。文本格式只记录字节数，不将其当作 token 数。
